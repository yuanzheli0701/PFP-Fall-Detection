# Ⅰ. 引言与问题定义

跌倒对老年人是重大健康风险。根据世界卫生组织（WHO）报告、经 Taramasco 等人（2025）引用的数据：65 岁以上人群中每年约 28–35% 会跌倒，70 岁以上升至 32–42%。后果从骨折到长时间倒地不起，许多老年人还会因此产生长期的「跌倒恐惧」。自动跌倒检测系统（FDS）的目标是尽快发出警报，尤其是对独居老人。

近年的 FDS 大多依赖机器学习，但面临共同的数据难题：走路、坐下等日常活动容易大量采集；而跌倒事件罕见、真实条件下难以捕捉、逼真模拟成本高昂。因此公开跌倒数据集规模小、类别严重不平衡，且通常只涉及少数受试者。在这样的数据上训练经典监督分类器，模型往往偏向多数类，且难以泛化到新的人。

度量学习提供了一条替代路径。它不直接学习「信号 → 类别标签」的映射，而是学习一个表示空间（嵌入空间），使相似事件彼此靠近、不同事件彼此远离；分类通过比较距离完成，例如比较到最近邻或到类原型的距离。这类方法本就为「每类样本很少」的场景设计，因此是跌倒检测的有力候选。

本综述服务于一个项目：在 QUIDA 多模态数据集（Taramasco et al., 2025）上比较上述两条路线，使用两种传感器——佩戴在身上的加速度计和毫米波（mmWave）雷达。综述有四个目标：

- ① 介绍两种传感模态与 QUIDA 数据集；

- ② 回顾用于跌倒检测的监督深度学习基线（CNN 与 LSTM）；

- ③ 回顾度量学习方法：孪生网络、对比损失与三元组损失、基于最近邻或原型的分类；

- ④ 回顾多模态融合策略，随后论证项目所选方法的合理性。


# Ⅱ. 跌倒检测的传感模态

跌倒检测传感器通常分为三类：可穿戴、环境（非接触）、视觉（Taramasco et al., 2025）。RGB 摄像头等视觉传感器效果好，但引发隐私担忧。本项目使用一种可穿戴传感器和一种环境传感器，两者都能保护隐私。


## Ⅱ.1 可穿戴传感器：加速度计

三轴加速度计是跌倒检测中最成熟的模态。跌倒会产生特征性信号：短暂的自由落体阶段 → 尖锐的撞击峰值 → 一段静止期。加速度计便宜、每部智能手机都有，并能提供高频密集信号。其局限主要是实用层面的：设备必须佩戴并充电，否则监测就会中断。佩戴位置同样重要：靠近身体质心的位置（躯干或腰部）能给出最具代表性的信号。

*图1. 真实跌倒窗口（QUIDA · subject_1 · 加速度计 62.5 Hz · 10 秒窗）：撞击峰值 69.2 m/s²；前段平稳 → 自由落体与撞击 → 跌倒后静止——正文 Ⅱ.1「自由落体 → 尖锐撞击峰值 → 静止期」的真实样例。*


## Ⅱ.2 环境传感器：毫米波雷达

工作在 60 GHz 附近的毫米波雷达可以非接触地检测人，且不会生成可识别身份的图像。它能在黑暗中工作，用户无需佩戴任何设备。现代雷达输出稀疏三维点云，每个点带有位置和多普勒速度。多普勒分量直接测量运动身体部位的速度，使跌倒时突然的高速运动十分突出。Jin 等人（2020）表明，把 4D 毫米波点云按帧序列处理，可以支持可靠的跌倒检测。

雷达数据比加速度计数据更难处理：每帧检测到的点数会变化，原始数据没有固定大小。主要有两种策略：把每帧聚合成固定的手工特征（点数、平均多普勒、质心高度等），或者使用为点集设计的网络，如 PointNet（Qi et al., 2017）。后者需要多得多的训练数据。

# Ⅲ. 跌倒检测的监督深度学习

早期跌倒检测器使用加速度幅值阈值，或使用手工特征输入经典分类器（SVM、随机森林）。此后深度学习成为主流，因为它能从原始或轻度处理的信号中直接学习特征。对传感器时间序列而言，两大类架构占主导：卷积神经网络（CNN）与长短期记忆网络（LSTM）（Wang et al., 2019）。


## Ⅲ.1 基于 CNN 的方法

一维 CNN 让学到的滤波器沿信号窗口的时间轴滑动。每个滤波器检测一种局部模式（例如跌倒的尖锐撞击峰值），无论它出现在窗口何处。多层堆叠把这些局部模式组合成更高层的特征。在基于加速度计的跌倒检测上，CNN 在公开数据集上达到高准确率，同时保持很少的参数（Santos et al., 2019）。它们训练快、便于部署在嵌入式设备上，而且比大模型更不易过拟合——这在数据稀缺时尤为重要。


![图3. 一维卷积示意：滤波核 w = [−0.5, −1, 0, +1, +0.](C:/Users/13968/Documents/ChatGPT/PFP _ Fall detection/figures/en/fig_conv1d.png)

*图3. 一维卷积示意：滤波核 w = [−0.5, −1, 0, +1, +0.5]（K = 5）沿时间滑动；平坦段几乎无响应，撞击处响应最强——对应正文 Ⅲ.1「滤波器检测局部模式」。*

卷积层由卷积核大小（kernel size）和滤波器数量定义。一个大小为 K、作用于 C 个输入通道的滤波器含有 K × C + 1 个权重（+1 为偏置），与窗口长度无关——这正是模型能保持很小的原因。最大池化（max-pooling）保留每个区间中最强的响应，因此当撞击在时间上略微移动时输出变化不大。某个输出值的「感受野」（receptive field）是它所依赖的窗口区域：每经过一层增加 K − 1 个采样点；经过一次步长为 2 的池化后再翻倍为 2(K − 1) 的增长。因此，选择网络深度时必须考虑窗口长度。

*图4. 1D-CNN 基线结构：3 层卷积 + 2 次池化 + 全局平均池化 + 全连接，约 9.3k 参数；红框 RF 为感受野（最终 24 点 ≈ 62.5 Hz 下 0.38 秒）——呼应正文 Ⅲ.1 的参数量与感受野段落。*

## Ⅲ.2 基于 LSTM 的方法

循环神经网络逐步处理序列，并保留「之前发生了什么」的内部记忆。LSTM（Hochreiter & Schmidhuber, 1997）加入门控机制控制记忆的保留与遗忘，解决简单循环网络的梯度消失问题。LSTM 适合事件顺序重要的数据。跌倒是一系列阶段：正常运动 → 快速下落 → 撞击 → 静止躺卧。Musci 等人（2021）使用循环网络在可穿戴设备上进行在线跌倒检测。对雷达，Jin 等人（2020）把循环自编码器与点云帧序列结合。也存在混合 CNN-LSTM 模型：CNN 提取局部特征，LSTM 建模其随时间的变化。


![图5. RNN 按时间展开：隐状态 h_t 把过去的信息逐帧传递；每一步复用同一](C:/Users/13968/Documents/ChatGPT/PFP _ Fall detection/figures/en/fig_rnn_unroll.png)

*图5. RNN 按时间展开：隐状态 h_t 把过去的信息逐帧传递；每一步复用同一组权重（权重共享）——对应正文 Ⅲ.2「逐步处理序列、保留内部记忆」。*

LSTM 单元在时间步之间携带一个「单元状态」（cell state），由三个学到的门控制：输入门决定写入记忆的内容，遗忘门决定保留的内容，输出门决定读出的内容。单元状态在每个时间步主要通过加法而不是完整的矩阵乘法更新，因此信息可以跨越很多步而不过度衰减。这正是网络能够把跌倒的各个阶段（下落、撞击、静止）关联起来的原因，即使它们相隔好几帧。

## Ⅲ.3 数据稀缺与不平衡带来的局限

在跌倒检测场景中，这些监督模型有三个共同弱点：

- 类别不平衡。QUIDA 中每个跌倒对应 3 个非跌倒，真实世界比例更高；模型可能在漏掉很多跌倒的同时获得很高的准确率。常见对策（类权重、过采样、数据增强）并不能改变根本问题。

- 受试者太少。只有 10 名参与者，模型可能学到特定人的运动风格，而非跌倒的一般特征。用留一受试者验证衡量时，在未见过的受试者上的表现通常远低于随机划分。

- 类别固定。分类器的输出层绑定于训练时见过的类别；增加新的跌倒类型或适配新的人都需要重新训练。

这些局限正是度量学习的动机：它专为「从少量样本学习」而设计，并依靠比较而非固定的输出层来分类。


# Ⅳ. 度量学习


## Ⅳ.1 原理

度量学习训练一个神经网络 f，把每个输入 x 映射为嵌入向量 f(x)，通常维度较低并归一化为单位长度。训练目标是让两个嵌入之间的距离反映输入的相似程度：两个跌倒样本应当靠近，跌倒窗口与行走窗口应当远离。网络不被要求直接输出类别；分类在之后通过比较嵌入空间中的距离完成。

这改变了数据的使用方式：监督分类器从单个带标签样本学习，而度量学习模型从样本对（pair）或三元组（triplet）学习。N 个样本可组成约 N²/2 量级的样本对，因此小数据集仍能提供大量训练信号。这也是度量学习被广泛用于小样本学习（few-shot learning）的原因（Koch et al., 2015; Snell et al., 2017）。


## Ⅳ.2 孪生网络与对比损失

孪生网络（siamese network）由两个完全相同、共享权重的分支组成（Chicco, 2021）。每个分支接收一对输入中的一个并输出其嵌入。由于权重共享，两个输入被投影到同一空间，然后计算两个嵌入之间的距离 d。对比损失（Hadsell et al., 2006）在带标签样本对上训练网络：


**公式：** `L = y·d² + (1 − y)·max(0, m − d)²`

其中 y = 1 表示两个输入属于同类，y = 0 表示不同类；m 是间隔（margin）。相似样本对被拉近，不相似样本对被推远，直到距离超过 m；已经相距足够远的样本对不再产生贡献。Koch 等人（2015）表明孪生网络能从单个示例识别新类别，这使其成为小样本问题的参考方法。

> 译注：公式逐项含义、数值例子与「注意 y 的定义方向」见【附录A·公式1】。


## Ⅳ.3 三元组网络与三元组损失

三元组损失由 FaceNet（Schroff et al., 2015）推广，一次处理三个样本：锚点 a、同类正样本 p、异类负样本 n。它要求锚点到正样本的距离比到负样本至少近一个间隔 α：


**公式：** `L = max(0, ‖f(a) − f(p)‖² − ‖f(a) − f(n)‖² + α)`

对比损失约束的是绝对距离，而三元组损失只约束相对距离：这给嵌入空间更大的自由度，通常带来更好的表示。主要难点在于三元组的选择——大多数随机三元组「太容易」：已满足间隔、不产生梯度。因此 FaceNet 选择「半困难（semi-hard）」负样本：比正样本远，但仍落在间隔之内。Hermans 等人（2017）提出「批次内最难（batch-hard）」挖掘：在每个批次中取最难的正样本和负样本；他们还建议构建 P 个类别、每类 K 个样本的批次，保证每个批次中每个类别都有代表。这种平衡采样对跌倒检测这类不平衡问题尤为重要。

> 译注：公式的三段式理解（合格→0、不合格→拉近正样本/推远负样本）、数值例子与挖掘策略，见【附录A·公式2】。


## Ⅳ.4 嵌入空间中的分类

嵌入网络训练完成后，新输入通过与带标签的参考样本比较嵌入来分类。两种策略常用。


### Ⅳ.4.a 最近邻分类（k-NN）

k-NN 分类器找出距查询样本最近的 k 个参考嵌入，并赋予其中占多数的类别。它无需额外训练，且能自然处理复杂的类形状。但它对噪声样本和类别不平衡敏感：当非跌倒远多于跌倒时，一个模棱两可窗口的最近邻更可能是非跌倒；其推理成本也随存储的参考样本数增长。


### Ⅳ.4.b 基于原型的分类

原型网络（Snell et al., 2017）用单个原型 c_k 表示每个类别 k，即该类参考样本 S_k 的嵌入均值：


**公式：** `c_k = (1/|S_k|) · Σ_{x_i ∈ S_k} f(x_i)`

查询样本被分配给距离其原型最近的类。无论某类有多少样本，它都恰好只有一个代表，因此决策不会偏向多数类。原型的计算廉价、且易于更新——加入一个新受试者的跌倒样本，只需移动跌倒原型。局限在于：当一类具有多个明显不同的形态（例如前倒与侧倒）时，单个均值可能表示不好。每类使用多个原型（每种跌倒类型一个）是一种可能的扩展。

> 译注：逐符号解释与「为什么抗不平衡」见【附录A·公式3】。


### Ⅳ.4.c 比较

*表 2. k-NN 与原型分类在嵌入空间中的比较。*

| 准则 | k-NN | 原型 |
| --- | --- | --- |
| 额外训练 | 无 | 无（嵌入的均值） |
| 对类别不平衡的鲁棒性 | 低 | 高 |
| 对噪声样本的鲁棒性 | 低（取决于 k） | 高（平均效应） |
| 多形态类别 | 处理良好 | 需要每类多个原型 |
| 推理成本 | 随参考集增长 | 每类一次距离计算 |


## Ⅳ.5 小样本跌倒检测

已有少数研究把度量学习应用于跌倒检测。Droghini 等人（2018）在音频特征上训练孪生网络，表明可用极少的跌倒样本训练出检测能力。Bakshi 与 Rajan（2021）提出用于小样本跌倒检测的浅层孪生网络，表明紧凑模型也能从有限跌倒样本中学到有用的相似度函数。两项工作都证实小样本设定适合跌倒检测。据我们所知，度量学习尚未应用于 QUIDA 数据集，也尚未用于可穿戴与雷达数据融合的跌倒检测。


# Ⅴ. 多模态传感器融合

组合不同性质的传感器可以同时减少误报和漏报，因为每种传感器能弥补其他传感器的盲区（Wang et al., 2020; Taramasco et al., 2025）。加速度计捕捉身体自身的运动，但如果不佩戴就失效；雷达监视房间，但可能被其他移动物体干扰，或当人走出其视野时失效。融合策略通常按传感器组合的层级分类：

- 早期融合（数据级）。在进入任何模型之前，把原始或预处理信号合并为单一输入。简单，但要求所有信号共享同一时间基准与格式。

- 中间融合（特征级）。每种传感器有自己的编码器，所学特征或嵌入在被拼接后送入共享的最终层。每个编码器都能针对其数据类型定制。

- 晚期融合（决策级）。每种传感器有完整的独立模型，其输出（概率、分数或距离）被组合，例如平均或投票。对传感器缺失稳健，但无法学习模态间的交互。

QUIDA 的主要技术障碍是采样率差异：加速度计 62.5 Hz 对雷达 8.3 Hz，约 7.5 倍。早期融合要么对加速度计降采样（丢失撞击峰值的精细形状），要么对雷达插值（产生人工值）。中间与晚期融合避免了这个问题：每条分支在同一时间窗内以各自的原生采样率处理。QUIDA 的切分已经为所有传感器提供了等长的同步窗口，只是每个传感器的采样点数不同。

中间融合与度量学习天然契合：两个传感器编码器可以联合训练，使拼接后的嵌入满足对比损失或三元组损失；融合后的嵌入空间随后可用与单传感器情形相同的 k-NN 或原型分类器。

| --- | --- | --- | --- | --- |
| 1D-CNN 分类器 | 单样本 | 低 | 中等 | 偏向多数类 |

## Ⅵ.1 选定方法

监督基线。对加速度计：小型 1D-CNN，作用于 4 秒窗口（约 250 采样点 × 3 轴），以较少参数捕捉撞击峰值。对雷达：先把每帧总结为一组固定特征——点数、平均和最大多普勒速度、平均高度、质心位置和点散布；所得序列（约 33 帧 × 8 个特征）送入小型 LSTM，建模跌倒的时间演化（高度下降、多普勒峰值）。不采用 PointNet 等点集网络，因为它们需要比 QUIDA 更多的数据。如果时间允许，还会在加速度计上测试 LSTM，以便在同一传感器上比较两种架构。

## Ⅵ.2 评估方案

- 留一受试者交叉验证（LOSO）：十折，每折在一个训练中从未见过的受试者上测试。

- 所有方法使用完全相同的划分，使差异只来自模型本身。

- 窗口化：以每个标注跌倒为中心的 4 秒窗口。非跌倒窗口只有在不与跌倒窗口重叠、且在撞击后留有边距时才保留，从而跌倒后的静止期绝不会被标注为非跌倒。

- 指标：跌倒召回率（灵敏度）、精确率、F1 分数和特异度。在不平衡类别下，单看准确率会产生误导。

- 缩减训练集：每个方法先在来自留出受试者的每类 k 个带标签窗口上评估（k = 1, 2, 4, 8），然后用训练跌倒样本的 100%、50%、25% 和 10% 重新训练，所有方法使用相同的子集。

- 杜绝增强泄漏：测试受试者记录的增强副本绝不能出现在训练集中。

# 附录A · 公式详解（这份报告里的每个式子）

> 说明：这一节是给「看懂」用的——先讲每个符号是什么，再讲公式在干什么、为什么这样设计，最后给数值例子。可以配合正文 Ⅳ.2、Ⅳ.3、Ⅳ.4.b 一起看。


## 公式1｜对比损失 Contrastive Loss（孪生网络）


**公式：** `L = y·d² + (1 − y)·max(0, m − d)²`

先看符号：d 是两个样本的嵌入向量之间的欧氏距离，d = ‖f(x₁) − f(x₂)‖，由网络输出直接算出；y 是标签，y = 1 表示两个输入同类（同是跌倒，或同是非跌倒），y = 0 表示不同类；m 是间隔（margin），一个正数超参数（例如 m = 1），它规定异类样本至少要被推开多远；max(0, ·) 是「见负取零」的截断，意味着超额完成的样本对不再被惩罚。

逐项拆解：第一项 y·d² 只有同类对才激活——最小化 d² 就是把同类样本的嵌入往一起拉拢。第二项 (1 − y)·max(0, m − d)² 只有异类对才激活：若 d ≥ m（已经够远），max 取 0，损失为 0，不再推；若 d < m（挨得太近），损失 = (m − d)² > 0，训练继续把它们推远，直到 d = m 为止。

数值例子（设 m = 1）：同类对 d = 0.6 → L = 0.36，训练把两者拉近；异类对 d = 0.4 → L = (1 − 0.4)² = 0.36，训练把两者推远；异类对 d = 1.2 → L = 0，完全不参与。

> 易错点：原始 Hadsell 等（2006）论文中 y = 1 表示「不同类」，本报告为叙述方便改成 y = 1 表示「同类」。两种写法数学上等价，但读任何文献时都要先确认 y 的定义方向。

为什么需要它：这是最朴素的「同类拉近、异类推远」。它的问题在于约束「绝对距离」——它要求所有异类对都被推到固定半径 m 之外，而现实中「跌倒 vs 走路」和「前倒 vs 侧倒」的「远」其实不在一个尺度上。这就引出了三元组损失。


## 公式2｜三元组损失 Triplet Loss（FaceNet 风格）


**公式：** `L = max(0, ‖f(a) − f(p)‖² − ‖f(a) − f(n)‖² + α)`

符号：a 是锚点（anchor，基准样本）；p 是与 a 同类的正样本（positive）；n 是与 a 不同类的负样本（negative）；f(·) 是嵌入网络的输出向量；‖f(a) − f(p)‖² 是锚点到正样本距离的平方（记作 d⁺²）；‖f(a) − f(n)‖² 是锚点到负样本距离的平方（记作 d⁻²）；α 是间隔（margin），正数超参数，例如 0.2。

直觉：公式要求「锚点到正样本的距离，至少比到负样本近 α」。把括号内的条件重写一下：损失为 0 等价于 d⁺² + α ≤ d⁻²，也就是 d⁻² − d⁺² ≥ α（「负样本距离至少比正样本距离大 α」）。

分段理解：① 简单三元组（d⁻² − d⁺² ≥ α，条件已满足）→ L = 0，没有梯度，对训练毫无贡献——这正是随机三元组大多「没用」的原因；② 未达标（d⁻² − d⁺² < α）→ L = d⁺² − d⁻² + α > 0，梯度把 d⁺ 拉小、把 d⁻ 推大，直到条件满足。数值例子（α = 0.2）：d⁺ = 0.5（平方 0.25）、d⁻ = 0.6（平方 0.36）→ L = 0.25 − 0.36 + 0.2 = 0.09 > 0，继续优化；换成 d⁺ = 0.2（0.04）、d⁻ = 0.9（0.81）→ 0.04 − 0.81 + 0.2 < 0 → L = 0，跳过。

为什么说它只约束「相对」距离：公式只关心 d⁻² − d⁺² 这个差，不要求 d⁺ 绝对小、也不要求 d⁻ 绝对大。嵌入空间的自由度更大——「同类要近、异类要远」只需在局部成立，不必把全部异类推到同一个绝对半径之外。

训练技巧（对应正文）：随机三元组大多太简单（L = 0），所以要「挖掘」难例。semi-hard 负样本 = 比正样本远、但还没超过 margin 的负样本，有梯度又不至于太难；batch-hard = 在每个批次内取最难的正样本与负样本；P×K 采样 = 批次由 P 个类别、每类 K 个样本组成（例如 P = 4、K = 8 → 32 个样本），保证每类都在场——这直接对抗 1:3 的类别不平衡。

> 补充（帮助理解）：如果嵌入做了单位长度归一化，则 ‖f(a) − f(p)‖² = 2 − 2·⟨f(a), f(p)⟩，即「距离平方」与「余弦相似度」一一对应；拉近距离 = 提高余弦相似度。


## 公式3｜类原型 Class Prototype（原型网络）


**公式：** `c_k = (1/|S_k|) · Σ_{x_i ∈ S_k} f(x_i)`

符号：k 是类别编号（例如 1 = 跌倒、0 = 非跌倒）；S_k 是类别 k 的参考样本集合（已标注的样本）；|S_k| 是集合中的样本个数；x_i 是第 i 个参考样本；f(x_i) 是它的嵌入向量；c_k 是类别 k 的原型，等于该类所有参考嵌入的算术平均（向量逐维求平均）。

直觉：每个类在嵌入空间里的「质心」（可以想象成「平均脸」）。分类一个新样本 q 时：计算 f(q) 到每个 c_k 的距离，取最近的类的标签。

为什么抗不平衡（对应表 2）：无论跌倒类只有 10 个样本、非跌倒类有 30 个，每个类最后都只浓缩成一个原型点——相当于「每类一票」。而 k-NN 直接数近邻的票数，多数类天然占优。

为什么容易更新：来了新受试者的跌倒样本，只需把新嵌入并入均值（加权平均，无需重新训练网络），原型就被「移动」过去了。

局限：一个均值可能「谁都不像」——如果一类内部存在明显子类型（前倒/侧倒形态差异大），用一个点表示会失真。解决办法是每类使用多个原型（每种跌倒子类型一个），文中作为扩展提出。


## 补充｜两处「小式子」（Ⅲ.1 与 Ⅲ.2 新增段落里的）

① 滤波器参数量 K × C + 1：一维卷积中，一个滤波器的权重数 = 核长 K × 输入通道数 C，再加 1 个偏置（bias）。关键点：它与「窗口长度」无关——这就是 CNN 参数少的原因。例：K = 5、C = 3（三轴加速度）→ 5×3+1 = 16 个权重。

② 感受野（receptive field）：某个输出值「看得到」的输入范围。每经过一层卷积（核长 K）增加 K − 1 个采样点；如果某层让数据长度减半（步长 2 的池化），之后的每 1 个采样点代表原信号 2 个点，因此增长也翻倍为 2(K − 1)。例：K = 5，则每层 +4；过池化后每层等效 +8。这决定了网络要「看完整段 4 秒窗口」需要多少层——也正是文中说「深度必须结合窗口长度选择」的原因。

③ LSTM 的门（Ⅲ.2）：输入门 i、遗忘门 f、输出门 o 各自是一个小型神经网络，输出 0–1 之间的「闸门开度」，分别控制写入多少、保留多少、读出多少。单元状态 c_t 的更新以加法为主：c_t = f ⊙ c_{t−1} + i ⊙ g_t（g_t 为新候选记忆，⊙ 为逐元素乘法）。因为主路径是加法而不是每步都乘矩阵，梯度可以「高速公路」般流过很多时间步——这就是它能记住「下落 → 撞击 → 静止」这类跨多帧阶段的原因。
